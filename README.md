# 🏛️ EXPLORE: Petualangan 24 Lantai Perpusnas

**EXPLORE: Petualangan 24 Lantai Perpusnas** adalah game edukatif interaktif berbasis web (*Single-File HTML5 Application*) yang mengajak pemain menjelajahi gedung perpustakaan tertinggi di dunia — **Perpustakaan Nasional Republik Indonesia (Jl. Medan Merdeka Selatan No. 11, Jakarta)** — mulai dari Lantai 1 hingga Lantai 24.

## ✨ Fitur Utama
1. **4 Karakter Pemustaka dengan Jalur Kebutuhan Unik:**
   - 🧒 **Raka (9 Tahun - Anak-Anak):** Fokus Lantai 1 → 2 → 7 → 4 → 24.
   - 👧 **Sinta (16 Tahun - Pelajar SMA):** Fokus Lantai 1 → 2 → 8 → 21 & 22 → 24.
   - 🎓 **Bima (22 Tahun - Mahasiswa/Peneliti):** Fokus Lantai 1 → 2 → 3 → 9 → 11 & 12/12A → 14–19 → 21 & 22 → 23 → 24.
   - 👴 **Pak Hendra (65 Tahun - Lansia/Pensiunan):** Fokus Lantai 1 → 2 → 6 → 7 → 23 → 24.
2. **Simulasi Prosedur Nyata Layanan Perpusnas (*Tanya Pustakawan*):**
   - **Wajib Loker Lantai 1:** Menitipkan tas ransel dan mengambil *Tas Transparan* + *Kunci Loker* sebelum naik ke lantai layanan koleksi.
   - **Wajib Keanggotaan Lantai 2:** Mendaftar *Kartu Anggota Perpusnas (SAKTI)* dan mengenal *Smart Locker* untuk mengakses fasilitas peneliti, meminjam buku, serta membuka *e-Resources*.
   - **Wajib Pencarian OPAC / Indonesia OneSearch:** Menemukan Nomor Panggil (*Call Number*) buku terlebih dahulu saat berada di lantai koleksi (Lantai 12, 12A, 14–19, 21, 22, 23).
3. **Eksplorasi Penuh 24 Lantai & Mini-Game Klasifikasi DDC:**
   - Mencakup seluruh 24 lantai (termasuk Lantai 12A, Zona Staf Lantai 5, Data Center & Masjid Lantai 6, Koleksi Deposit Lantai 10, Mini-Game Klasifikasi Dewey 000–499 di Lantai 21 & 500–999 beserta etika Troli Buku di Lantai 22, hingga Balkon Pandang Monas di Lantai 24).
4. **Penyimpanan Otomatis (`localStorage`):**
   - Progres lantai, Poin Literasi (XP), Stamina, Inventory, dan Lencana (*Duta Pemustaka Perpusnas*) tersimpan otomatis di browser.

## 🚀 Cara Memainkan
Cukup buka file `index.html` di browser modern apa pun (Chrome, Edge, Firefox, Safari) di Desktop maupun Smartphone, atau akses langsung melalui tautan **GitHub Pages** repositori ini.

## 🛠️ Teknologi yang Digunakan
- **HTML5 Semantic**
- **Tailwind CSS (via CDN)** + Animasi CSS Kustom
- **Vanilla JavaScript (ES6+)** & Browser `localStorage` API
